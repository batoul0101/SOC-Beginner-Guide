# 🎯 تحليل التهديدات في SOC

## 🎯 مقدمة
تحليل التهديدات يعني اكتشاف وفهم الهجمات الأمنية. في هذا الدليل، سنتعلم **كيف نتعرف على الهجمات الشائعة** و**كيف نتعامل معها**.

## 📊 أنواع الهجمات الشائعة

### **1. هجمات SSH (القوة الغاشمة)**
ماذا يحدث: يحاول المهاجم تخمين كلمة مرور SSH
كيف تعرفها:

محاولات كثيرة فاشلة في اللوجات

نفس IP يحاول مرات عديدة

كود تحليل بسيط:

text
```bash
# حساب محاولات SSH الفاشلة
grep "Failed password" /var/log/auth.log | wc -l

# عرض IPs المهاجمة
grep "Failed password" /var/log/auth.log | awk '{print $11}' | sort | uniq -c
2. هجمات مواقع الويب (SQL Injection)
text
ماذا يحدث: يحاول المهاجم سرقة بيانات الموقع
كيف تعرفها:
- ظهور كلمات مثل ' OR '1'='1 في اللوجات
- أخطاء قاعدة بيانات

كود تحليل بسيط:
```bash
# البحث عن محاولات SQL Injection
grep -i "union\|select\|or 1=1" /var/log/apache2/access.log
3. برامج ضارة (Malware)
text
ماذا يحدث: برنامج خبيث يضر بجهازك
كيف تعرفها:
- جهازك أصبح بطيئاً
- اتصالات غريبة للإنترنت
- ملفات غريبة في مجلدات النظام
🔍 خطوات التحليل البسيطة
الخطوة 1: جمع المعلومات
bash
# 1. شاهد اللوجات الأخيرة
tail -100 /var/log/auth.log

# 2. تحقق من العمليات النشطة
top

# 3. شاهد الاتصالات النشطة
netstat -tunap
الخطوة 2: البحث عن علامات مشبوهة
text
ابحث عن:
1. محاولات دخول كثيرة فاشلة
2. IPs من بلدان غريبة
3. عمليات تستخدم معالجك كثيراً
4. اتصالات لمنافذ غريبة
الخطوة 3: اتخاذ إجراء
bash
# 1. أوقف عملية مشبوهة
kill [رقم_العملية]

# 2. احظر IP مشبوه
iptables -A INPUT -s [IP_المشبوه] -j DROP

# 3. غير كلمات المرور
passwd [اسم_المستخدم]
